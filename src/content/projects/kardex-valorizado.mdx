Sistema para procesar grandes volúmenes de movimientos de inventario desde archivos Excel,
detectar inconsistencias matemáticas mediante el método de Costo Promedio Ponderado (CPP),
y generar reportes analíticos para auditoría y control contable. Incluye motor de recálculo
automático, alertas de saldo negativo, panel de análisis con métricas operativas y un sistema
de validaciones diseñado para no alterar la información original.
