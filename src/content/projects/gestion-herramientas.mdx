Sistema SPA para la gestión de inventario, préstamos, devoluciones, compras y proveedores
de herramientas físicas. Incluye autenticación con JWT y protección de rutas, cierre
automático de préstamos cuando todas las herramientas son devueltas, generación de
comprobantes en PDF, y un modelo de datos relacional con transacciones SQL para
operaciones críticas como compras y préstamos.
